# The World in One Day — 18 November 2026

A program that draws one image summing up the world's news of Wednesday 18 November 2026, for [make.fun](https://make.fun/bounty/news-image-20261118)'s news-image-20261118 bounty. Six stories: APEC opens in Shenzhen with Xi greeting Trump, US strikes on Iran answered in the Gulf, Ukraine hits the Kerch Bridge again, Peltola wins Alaska and Democrats take the Senate, Ebola passes 11,000 cases in Congo, and Voyager 1 reaches one light-day from Earth.

Node 22 standard library only, no network. The program draws the front page procedurally with a hand-written 5x7 bitmap font and encodes the PNG itself (zlib), so both runs write byte-identical output.


Run: `mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts`
